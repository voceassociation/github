VOCE AI Governance Institute · Agent Conformance · v1.0

An agent is not controlled because a policy says it is. The evidence must survive the execution.

VOCE Agent Conformance turns the European Agent Infrastructure Reference into a control-by-control evidence matrix. It does not issue a simplistic score. It identifies what is absent, merely declared, documented, tested or verified in operation — and where one authority gap can invalidate an otherwise mature architecture.

Three levels of assurance.
01

Self Assessment

The institution records its own state and evidence references. Useful for gap analysis and procurement preparation.

02

Reviewed

VOCE specialists examine architecture, policies, contracts, configurations and supplied test evidence.

03

Observed

VOCE specialists review evidence and observe selected permissions, logs, revocations, approvals or tests in the operating environment.

Reviewed and Observed are not self-declared labels.
