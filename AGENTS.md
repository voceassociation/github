# VOCE repository working rules

For course authoring or revision, read docs/education/COURSE-ACCEPTANCE.md before editing. Priority instruction of 26 October 2026: select ONLY courses below 20,000 normalized characters excluding bibliography, navigation and metadata. Check current main AND saved sources before selecting, including a checkpoint course. Preserve every course already at or above that threshold without extending it to 75,000. For eligible new rewrites the prior substantial-teaching requirements remain; never combine old and new editions to inflate a count. Technical courses target engineers and professional VVIC readers. Article/social-post length limits do not apply to these courses.

Do not claim that a successful build, a timer, a character counter or source-link presence demonstrates pedagogical or scientific quality. Record the specific checks performed for each course. Do not claim completion of all 120 courses from a sample review.

Preserve course URLs, identities, official branding and publication policies. Preserve unrelated work. The historical scripts/build-course-workshops.py rewrites pages from short capsules and must not overwrite long editions. The engineering manifest identifies hand-authored sources; use their explicit renderer.

Use only sources actually consulted for the assertions they support. European frameworks guide design; no invented formal alignment, qualification, partnership or accreditation. Preserve the separate daily-course task unless the user asks to change it.

Track preserved courses separately from rewritten and published courses; do not require all 120 to be rewritten. Do not report work as continuing unattended unless an actual running task exists.
