Dans l'économie numérique, ce modèle change. De nombreuses jeunes entreprises possèdent très peu d'infrastructures, elles assemblent des API déjà existantes.

Une API pour vérifier l'identité.

Une autre pour accepter les paiements.

Une troisième pour envoyer des messages.

Une quatrième pour utiliser une intelligence artificielle.

Une cinquième pour analyser les données.

En quelques semaines, il devient possible de lancer un service qui aurait nécessité plusieurs années de développement il y a seulement dix ans.

Les ingénieurs parlent de "composable architecture".

Au lieu de construire chaque composant, l'entreprise assemble des briques spécialisées déjà disponibles. Cette approche accélère considérablement l'innovation, mais elle crée aussi une nouvelle fragilité.

L'entreprise maîtrise ce qu'elle construit, elle maîtrise beaucoup moins ce qu'elle assemble.

Si une API change ses règles, augmente ses tarifs, limite son utilisation ou disparaît, c'est parfois tout le modèle économique qui doit être repensé.

Cette dépendance est rarement visible pour les investisseurs comme pour les clients, pourtant, elle devient un critère majeur d'évaluation.

Deux entreprises proposant exactement le même service peuvent avoir des niveaux de risque totalement différents selon les API sur lesquelles elles reposent.

Le sujet est encore peu abordé en Europe. Nous continuons souvent à mesurer la valeur d'une entreprise par ses produits ou son intelligence artificielle.

Les ingénieurs regardent désormais une autre question. Combien d'API critiques seraient impossibles à remplacer si elles disparaissaient demain?

Plus ce nombre augmente, plus le risque stratégique grandit.

Demain, les entreprises les plus solides ne seront peut-être pas celles qui possèdent le plus de technologies, ce seront celles qui sauront dépendre du plus petit nombre possible d'infrastructures qu'elles ne contrôlent pas.

Les API ont été conçues pour accélérer l'innovation, elles obligent désormais les dirigeants à repenser une notion beaucoup plus ancienne: l'indépendance.

PANTALONE

Construire vite est une force. Savoir de quoi dépend réellement sa maison est une sagesse.
