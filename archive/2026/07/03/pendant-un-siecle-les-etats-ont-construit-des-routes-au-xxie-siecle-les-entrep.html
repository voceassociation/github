Lorsqu'un Européen utilise une banque, réserve un billet d'avion ou consulte un dossier médical, il imagine que le service fonctionne grâce au logiciel affiché sur son écran.

En réalité, ce logiciel emprunte souvent des dizaines d'API appartenant à d'autres entreprises.

Chaque API remplit une fonction précise: vérifier une identité, calculer un itinéraire, traduire un texte, authentifier un paiement, analyser une fraude ou interroger une intelligence artificielle.

Le logiciel devient alors une succession de passages obligés.

Les ingénieurs parlent d'orchestration de services.

Le grand public, lui, ne voit rien.

Pourtant, une transformation économique majeure est en cours.

À chaque fois qu'une entreprise utilise une API externe, elle accepte les règles imposées par son propriétaire: prix, limites d'utilisation, disponibilité, évolution technique ou conditions d'accès.

Autrement dit, elle circule sur une infrastructure qu'elle ne possède pas.

Le phénomène ressemble à un réseau autoroutier privé.

Construire une nouvelle route coûterait des années. Il devient donc plus simple d'emprunter celle qui existe déjà, même si son propriétaire peut modifier les conditions de circulation.

Plus une API devient incontournable, plus le coût de la quitter augmente.

Les économistes parlent de "coût de changement".

Ce coût n'est pas seulement financier.

Il faut parfois réécrire des milliers de lignes de code, reformer les équipes, modifier les applications clientes et interrompre temporairement certains services.

Changer d'API peut devenir plus coûteux que continuer à payer.

C'est ici que se construit une nouvelle forme de dépendance.

L'Europe débat beaucoup des plateformes numériques.

Pourtant, le véritable verrou économique se déplace souvent un niveau plus bas, dans les API qui permettent aux plateformes, aux banques, aux administrations et aux entreprises de fonctionner ensemble.

Le risque n'est pas qu'une API devienne plus chère demain.

Le risque est qu'elle devienne tellement indispensable que son prix ne soit plus réellement négociable.

Les API ont été créées pour simplifier le développement logiciel.

Elles deviennent progressivement des infrastructures économiques dont la plupart des citoyens ignorent encore l'existence.

PANTALONE

La véritable dépendance commence souvent le jour où l'on oublie qu'une porte peut aussi se refermer.
