Shopify WebMCP: l'agent IA peut désormais aller jusqu'au bouton payer

28 septembre 2026.

Un client demande à son agent:

"Trouve-moi cette veste en taille M, applique mon code promo et prépare la livraison à Paris."

Shopify ouvre maintenant le checkout aux agents présents dans le navigateur.

Checkout WebMCP expose quatre outils: get_checkout, update_checkout, complete_checkout et navigate_to_storefront.

L'agent peut lire le checkout actif, modifier coordonnées, livraison, codes de réduction et certains paramètres de paiement, puis soumettre la commande après confirmation de l'acheteur.

Il ne reçoit pas un numéro de carte neuf. Pour Shop Pay, il peut sélectionner une carte déjà enregistrée. Si une connexion, un 3D Secure ou une extension bloquante intervient, le contrôle revient au client.

Le détail architectural est essentiel.

WebMCP agit sur le checkout réellement ouvert dans l'onglet. L'agent et l'acheteur voient le même état.

Shopify n'ouvre pas une API parallèle derrière le site. La page checkout enregistre directement des capacités structurées que l'agent peut appeler.

Le marchand n'a rien à installer sur les checkouts éligibles.

Checkout WebMCP et Checkout MCP réutilisent aussi le même objet UCP, les mêmes statuts et messages.

Le commerce web devient donc progressivement lisible et exécutable par des machines.

ULTRA®

Sans WebMCP, un agent navigateur doit souvent interpréter le DOM, localiser un bouton et simuler des clics.

Avec WebMCP, la page déclare ses fonctions métier.

Le checkout devient une surface d'action structurée.

Les limites restent importantes: B2B, embedded checkout, mobile SDK, draft orders, order edits, payment collection et certains parcours multi-boutiques restent hors périmètre. Les extensions de checkout peuvent encore exiger une action humaine.

Le standard reste émergent et le support navigateur est aujourd'hui principalement Chromium.

Pour une marque, le changement est profond: le storefront doit désormais servir simultanément l'humain qui regarde l'interface et l'agent qui appelle ses capacités.

LI!GHT WORKFORCE ©

Checkout WebMCP déplace vers l'agent une partie du travail transactionnel: recherche, panier, remise, adresse, livraison et préparation du checkout.

Le vendeur humain se concentre davantage sur l'exception, la négociation, le produit sensible et la relation premium.

La métrique intéressante devient le nombre de parcours clients qu'une marque peut absorber sans augmenter proportionnellement son assistance e-commerce.

Le site marchand reste visible.

Il devient aussi une infrastructure exécutable.

FIGARO

Le prochain client d'un site marchand aura parfois des yeux. Parfois une liste d'outils.
