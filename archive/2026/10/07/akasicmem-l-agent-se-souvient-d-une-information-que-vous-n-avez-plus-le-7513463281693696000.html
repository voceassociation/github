AkasicMEM: l'agent se souvient d'une information que vous n'avez plus le droit de lire

Alice peut consulter un contrat confidentiel.

Elle demande à un agent partagé d'en analyser une clause.

L'agent conserve ensuite une mémoire dérivée du document.

Quelques semaines plus tard, Bob utilise le même agent.

Bob n'a jamais eu accès au contrat.

Pourtant, si la mémoire est partagée sans reprendre les permissions d'origine, elle peut lui restituer une information interdite.

Le système source refuse l'accès.

La mémoire peut le contourner.

Le 22 septembre 2026, Jeongmin Bae et ses collègues publient AkasicMEM: Governed Enterprise Memory for Agents.

Ils nomment le problème: authorization continuity.

Lorsqu'une information quitte un document pour devenir mémoire d'agent, les restrictions du document doivent continuer à voyager avec elle.

La difficulté augmente lorsque cette mémoire est transformée.

Un contrat produit un résumé. Le résumé alimente une décision. La décision devient une nouvelle mémoire.

Supprimer le document initial ne suffit alors plus.

AkasicMEM conserve la filiation entre sources et mémoires. Lorsqu'une mémoire est rappelée, les politiques sont recomposées et les droits des sources réévalués.

Un changement de poste ou une révocation d'accès peuvent ainsi empêcher la réutilisation d'une connaissance toujours stockée.

Le 23 septembre, Google DeepMind présente une autre évolution: Private AI Compute doit accueillir une mémoire persistante côté serveur, chiffrée et utilisable entre plusieurs appareils.

Les assistants acquièrent donc une continuité qui dépasse la session.

Pour l'entreprise, une nouvelle catégorie documentaire apparaît.

La mémoire de l'agent.

ULTRA®

Un RAG retrouve une information dans une source existante.

Une mémoire d'agent peut produire une connaissance nouvelle à partir de plusieurs sources, puis la réutiliser longtemps après.

C'est cette dérivation qui complique la gouvernance.

Effacer une source ne garantit pas que les connaissances dérivées disparaissent avec elle.

AkasicMEM utilise une filiation transitive et réévalue les permissions au moment du rappel.

Le droit d'accès doit donc survivre au trajet de l'information.

Pour un board, les conséquences sont concrètes.

La politique de rétention devra couvrir documents, mémoires dérivées et dépendances. Les changements de rôle devront révoquer aussi l'accès aux souvenirs construits à partir d'anciennes permissions.

L'audit devra répondre à une question nouvelle: de quelles sources cette mémoire descend-elle?

L'entreprise ne gouvernera plus seulement ce que ses agents peuvent lire.

Elle devra gouverner ce qu'ils ont encore le droit de se rappeler.

ARGOS

Une mémoire devient un risque lorsqu'elle survit plus longtemps que l'autorisation qui l'avait rendue possible.
